## Tujuan

Membuat fungsi PHP bertipe untuk menghitung subtotal,
diskon, pajak, dan total pembayaran.

## Lingkungan

- XAMPP
- PHP: isi versi dari cek.php
- Visual Studio Code
- Browser

## Struktur Proyek

- cek.php: pemeriksaan versi PHP
- index.php: form dan hasil kasir
- uji.php: pengujian fungsi
- style.css: tampilan halaman
- includes/fungsi_kasir.php: pustaka fungsi
- bukti/: screenshot
- refleksi.md: jawaban refleksi

## Cara Menjalankan

1. Simpan proyek pada folder htdocs.
2. Aktifkan Apache.
3. Buka http://localhost/KasirFungsi_P04_Rafael/
4. Isi formulir.
5. Klik Hitung.

## Pengujian

Buka http://localhost/KasirFungsi_P04_Rafael/uji.php

Hasil yang diharapkan: sembilan pengujian LULUS.

## Aturan Perhitungan

Pajak dihitung setelah diskon.
